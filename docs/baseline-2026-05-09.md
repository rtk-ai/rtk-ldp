## Absence d'analytics

**Aucun outil d'analytics en place sur le site.** Pas de Plausible, GA, Fathom ou équivalent.
Conséquence : le taux de conversion install ne peut pas être mesuré avant/après refactor.
Action recommandée : installer Plausible (privacy-first, 1 ligne de script) avant ou pendant Phase 1.

## GitHub Pages — stratégie redirects

GitHub Pages ne supporte pas les redirects serveur natifs (`_redirects` = Netlify-only).
Options disponibles :
1. **JS hash-redirect inline** (choisi dans le plan) : rapide à implémenter, fonctionne pour les liens internes et bookmarks.
2. **Meta refresh** : SEO-neutre mais bloque le rendu 0-1s.
3. **Accepter la perte** pour les anciens anchors (peu de liens externes connus).

Décision : JS hash-redirect inline (option 1).

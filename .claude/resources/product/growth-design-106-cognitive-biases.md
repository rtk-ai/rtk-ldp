## 1. Filter Information

Comment les utilisateurs filtrent l'information qu'ils recoivent.

| #   | Bias / Principle               | Definition                                                                          |
| --- | ------------------------------ | ----------------------------------------------------------------------------------- |
| 1   | **Visual Hierarchy**           | Organiser les elements par importance pour guider la perception                     |
| 2   | **Selective Attention**        | Les utilisateurs se concentrent sur des stimuli specifiques en ignorant le reste    |
| 3   | **Banner Blindness**           | Les utilisateurs ignorent les elements ressemblant a des bannieres, meme pertinents |
| 4   | **Retroaction / Feedback**     | Les confirmations d'action reduisent l'incertitude                                  |
| 5   | **Hick's Law**                 | Le temps de decision augmente avec le nombre et la complexite des choix             |
| 6   | **Decoy Effect**               | Une option inferieure rend l'option preferee plus attractive                        |
| 7   | **Confirmation Bias**          | Les gens acceptent les informations qui confirment leurs croyances existantes       |
| 8   | **Expectations Bias**          | La perception est faconnee par les attentes prealables                              |
| 9   | **Centre-Stage Effect**        | Les elements au centre sont percus comme plus importants                            |
| 10  | **External Trigger**           | Des indices environnementaux declenchent des comportements specifiques              |
| 11  | **Survivorship Bias**          | Se concentrer sur les succes en ignorant les echecs                                 |
| 12  | **Fitts's Law**                | Le temps pour atteindre une cible depend de la distance et de la taille             |
| 13  | **Attentional Bias**           | Les pensees recurrentes influencent ce sur quoi on se concentre                     |
| 14  | **Cognitive Load**             | Effort mental total requis pour accomplir une tache                                 |
| 15  | **Anchoring Bias**             | Forte dependance a la premiere information rencontree                               |
| 16  | **Nudge Theory**               | Guidage subtil vers des actions souhaitables tout en preservant le choix            |
| 17  | **Contrast**                   | Les elements qui ressortent captent l'attention                                     |
| 18  | **Aesthetic-Usability Effect** | Un design visuellement agreable semble plus facile a utiliser                       |
| 19  | **Progressive Disclosure**     | Reveler l'information complexe graduellement pour eviter la surcharge               |
| 20  | **Empathy Gap**                | Difficulte a comprendre des emotions non ressenties actuellement                    |
| 21  | **Von Restorff Effect**        | Les elements distinctifs sont mieux retenus                                         |
| 22  | **Spark Effect**               | Les animations et micro-interactions creent des experiences engageantes             |
| 23  | **Framing Effect**             | Le choix des mots influence la perception et la reaction                            |
| 24  | **Signifiers**                 | Des indices visuels guident l'interaction avec l'interface                          |
| 25  | **Juxtaposition**              | Les elements proches et similaires sont percus comme lies                           |
| 26  | **Tesler's Law**               | La sur-simplification transfere la complexite a l'utilisateur                       |
| 27  | **Visual Anchors**             | Les elements visuels guident le mouvement des yeux                                  |
| 28  | **Priming Effect**             | Les stimuli precedents influencent les decisions suivantes                          |
| 29  | **Law of Proximity**           | Les elements proches sont percus comme associes                                     |

## 2. Search for Meaning

Comment les utilisateurs construisent du sens a partir de l'information.

| #   | Bias / Principle                | Definition                                                                |
| --- | ------------------------------- | ------------------------------------------------------------------------- |
| 30  | **Aha! Moment**                 | Prise de conscience soudaine de la valeur du produit                      |
| 31  | **Skeuomorphism**               | Le design digital imite des objets reels pour une comprehension intuitive |
| 32  | **Mental Model**                | Opinions preconcues sur le fonctionnement des systemes                    |
| 33  | **Familiarity Bias**            | Preference pour ce qui est connu plutot que nouveau                       |
| 34  | **Authority Bias**              | Tendance a etre d'accord avec les experts ou figures d'autorite           |
| 35  | **Social Proof**                | Les gens suivent les actions des autres pour valider leurs decisions      |
| 36  | **Humor Effect**                | L'humour rend l'information plus memorable et engageante                  |
| 37  | **Miller's Law**                | La memoire de travail retient ~7 (+-2) elements simultanement             |
| 38  | **Flow State**                  | Etat d'immersion totale ou le temps semble disparaitre                    |
| 39  | **Storytelling Effect**         | Les recits sont plus engageants et memorables que les faits bruts         |
| 40  | **Diderot Effect**              | Un nouvel achat declenche une spirale d'achats complementaires            |
| 41  | **Feedforward**                 | Anticiper et montrer ce qui va se passer avant l'action                   |
| 42  | **Reciprocity**                 | Les gens se sentent obliges de rendre ce qu'ils ont recu                  |
| 43  | **Curiosity Gap**               | Le desir de combler un ecart entre ce qu'on sait et ce qu'on veut savoir  |
| 44  | **Variable Reward**             | Les recompenses imprevisibles creent une forte motivation                 |
| 45  | **Group Attractiveness Effect** | Les elements groupes paraissent plus attractifs individuellement          |
| 46  | **Barnum Effect**               | Les descriptions vagues sont percues comme personnellement pertinentes    |
| 47  | **Mere Exposure Effect**        | La familiarite par repetition augmente la preference                      |
| 48  | **Halo Effect**                 | L'impression positive sur un trait influence le jugement global           |
| 49  | **Internal Trigger**            | Emotions ou pensees internes qui declenchent un comportement              |
| 50  | **Law of Similarity**           | Les elements visuellement similaires sont percus comme lies               |
| 51  | **Ikea Effect**                 | Les gens valorisent davantage ce qu'ils ont contribue a creer             |
| 52  | **Autonomy Bias**               | Les gens preferent avoir le controle et la liberte de choix               |

## 3. Time Perception

Comment les utilisateurs percoivent le temps et l'urgence.

| #   | Bias / Principle               | Definition                                                               |
| --- | ------------------------------ | ------------------------------------------------------------------------ |
| 53  | **Scarcity**                   | La rarete percue augmente la valeur desiree                              |
| 54  | **Urgency**                    | La pression temporelle accelere la prise de decision                     |
| 55  | **Loss Aversion**              | La douleur de perdre est 2x plus forte que le plaisir de gagner          |
| 56  | **FOMO (Fear Of Missing Out)** | La peur de manquer quelque chose pousse a l'action                       |
| 57  | **Status Quo Bias**            | Preference pour l'etat actuel, resistance au changement                  |
| 58  | **Sunk Cost Effect**           | Continuer un investissement a cause des ressources deja depensees        |
| 59  | **Default Effect**             | Les gens gardent l'option par defaut plutot que de changer               |
| 60  | **Commitment & Consistency**   | Une fois engages, les gens restent coherents avec leurs actions passees  |
| 61  | **Goal Gradient Effect**       | La motivation augmente a mesure qu'on approche du but                    |
| 62  | **Endowment Effect**           | Les gens valorisent davantage ce qu'ils possedent deja                   |
| 63  | **Self-Initiated Trigger**     | Les actions auto-initiees sont plus engageantes que les externes         |
| 64  | **Investment Loops**           | Chaque investissement de temps/effort renforce l'engagement              |
| 65  | **Fresh Start Effect**         | Les nouveaux debuts (lundi, 1er janvier) motivent le changement          |
| 66  | **Cashless Effect**            | Depenser est plus facile quand l'argent n'est pas physique               |
| 67  | **Self-Serving Bias**          | Attribuer les succes a soi et les echecs aux autres                      |
| 68  | **Foot-in-the-Door**           | Accepter une petite demande augmente la compliance aux suivantes         |
| 69  | **Hyperbolic Discounting**     | Preference pour les recompenses immediates vs futures                    |
| 70  | **Dunning-Kruger Effect**      | Les novices surestiment leurs competences, les experts les sous-estiment |
| 71  | **Optimism Bias**              | Tendance a croire que les mauvaises choses arrivent aux autres           |
| 72  | **Reactance**                  | Resister quand on sent que sa liberte de choix est menacee               |
| 73  | **Bye-Now Effect**             | L'exposition au mot "buy" diminue la resistance a l'achat                |
| 74  | **Temptation Coupling**        | Associer une tache desagreable a une recompense agreable                 |
| 75  | **Labour Illusion**            | Montrer le travail effectue augmente la valeur percue du resultat        |
| 76  | **Delayed Gratification**      | Reporter une recompense pour en obtenir une meilleure plus tard          |
| 77  | **Limited Access**             | L'acces restreint augmente la desirabilite                               |

## 4. Memory

Comment les utilisateurs se souviennent et oublient.

| #   | Bias / Principle               | Definition                                                                 |
| --- | ------------------------------ | -------------------------------------------------------------------------- |
| 78  | **Serial Position Effect**     | On retient mieux les premiers et derniers elements d'une liste             |
| 79  | **Peak-End Rule**              | On juge une experience par son pic emotionnel et sa fin                    |
| 80  | **Primacy Effect**             | Les premiers elements presentes ont plus d'impact                          |
| 81  | **Recency Effect**             | Les derniers elements presentes sont mieux retenus a court terme           |
| 82  | **Suffix Effect**              | Un element non pertinent en fin de liste degrade le rappel des precedents  |
| 83  | **Zeigarnik Effect**           | Les taches incompletes restent en memoire plus que les completes           |
| 84  | **Spacing Effect**             | L'apprentissage est meilleur quand il est espace dans le temps             |
| 85  | **Sensory Appeal**             | Les stimuli multi-sensoriels renforcent la memorisation                    |
| 86  | **Picture Superiority Effect** | Les images sont mieux retenues que les mots                                |
| 87  | **Method of Loci**             | Associer des informations a des lieux familiers aide la memoire            |
| 88  | **Shaping**                    | Renforcer progressivement les comportements vers l'objectif                |
| 89  | **Delighters**                 | Les surprises positives inattendues augmentent la memorisation             |
| 90  | **Provide Exit Points**        | Laisser l'utilisateur partir facilement augmente la confiance et le retour |
| 91  | **Self-Generation Effect**     | L'information auto-generee est mieux retenue que la recue passivement      |
| 92  | **Negativity Bias**            | Les experiences negatives ont plus d'impact que les positives              |
| 93  | **Availability Heuristic**     | Les evenements facilement rappeles semblent plus frequents                 |
| 94  | **Spotlight Effect**           | Les gens surestiment l'attention que les autres leur portent               |
| 95  | **Pratfall Effect**            | Les imperfections rendent les personnes/marques plus attachantes           |
| 96  | **Trigger (general)**          | Un stimulus qui declenche un comportement automatique                      |
| 97  | **Hindsight Bias**             | Tendance a croire qu'on aurait predit un evenement apres coup              |
| 98  | **Clustering**                 | Regrouper l'information en categories pour mieux la retenir                |
| 99  | **Levels of Processing**       | L'information traitee en profondeur est mieux retenue                      |
| 100 | **Absent-Mindedness**          | L'inattention cause des oublis dans les taches routinieres                 |
| 101 | **Suggestibility**             | Les informations post-evenement alterent les souvenirs                     |
| 102 | **Transience**                 | Les souvenirs s'effacent avec le temps sans renforcement                   |
| 103 | **Misattribution**             | Attribuer un souvenir a la mauvaise source                                 |
| 104 | **Blocking**                   | Incapacite temporaire a retrouver une information connue                   |
| 105 | **Persistence**                | Les souvenirs negatifs ou traumatiques persistent involontairement         |
| 106 | **Bias (general)**             | Tendance systematique a devier du jugement rationnel                       |

## Utilisation pour les audits UX

### Biais les plus pertinents pour EdTech (13-18 ans)

| Biais                      | Pourquoi pertinent                               |
| -------------------------- | ------------------------------------------------ |
| Goal Gradient Effect       | Motiver l'eleve a finir une activite             |
| Default Effect             | Reduire les decisions inutiles (titres, options) |
| Hick's Law                 | Simplifier les choix dans les interfaces mobiles |
| Peak-End Rule              | Soigner la fin de seance (feedback positif)      |
| Zeigarnik Effect           | Les taches non finies motivent le retour         |
| Serial Position Effect     | Placement strategique des CTA                    |
| Endowment Effect           | L'eleve "possede" ses documents/progres          |
| Aesthetic-Usability Effect | Un beau design pardonne les frictions            |
| Cognitive Load             | Minimiser l'effort mental en seance              |
| Feedforward                | Montrer ce qui va se passer avant l'action       |
| Social Proof               | Montrer que d'autres eleves utilisent la feature |
| Labour Illusion            | Montrer le travail de l'IA augmente la confiance |
| Progressive Disclosure     | Reveler les fonctionnalites au bon moment        |
| Flow State                 | Maintenir l'immersion en seance                  |
| Loss Aversion              | "Ne perds pas ta serie" pour l'engagement        |

# Source of Truth — Generated vs Editable

## Never Edit These Files

| File | Generated by | Source |
|------|-------------|--------|
| `src/content/docs/guide/` | `scripts/prepare-docs.mjs` | `rtk/docs/guide/**/*.md` |
| `src/data/docs-search-entries.ts` | `scripts/build-search-index.mjs` | docs content |
| `src/data/docs-anchor-map.json` | `scripts/prepare-docs.mjs` | docs content |
| `src/pages/rss.xml.ts` | Astro endpoint | `src/data/rss-entries.ts` |

These files are overwritten on every build. Edits will be lost silently.

## Always Edit These Files

| File | Purpose |
|------|---------|
| `src/data/rss-entries.ts` | RSS feed entries — add here manually |
| `src/pages/index.astro` | Landing page content + JSON-LD schemas |
| `src/pages/vox/index.astro` | Vox product page |
| `src/pages/icm/index.astro` | ICM product page |
| `src/styles/global.css` | Design tokens (source of truth) |
| `astro.config.mjs` | Astro + Starlight config, sidebar, redirects |

## When in Doubt

If a file has a comment like `// GENERATED — do not edit` or was modified by a script run,
it is generated. Check the table above before editing.

## RTK Source Changes

To update docs content: edit files in the sibling `rtk` repo under `docs/guide/`, then run:
```bash
pnpm dev:full   # or: node scripts/prepare-docs.mjs
```

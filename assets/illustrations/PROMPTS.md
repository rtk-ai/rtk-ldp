## Conseils de génération

- **Outil recommandé** : Midjourney v6.1 ou DALL-E 3 ou Flux Pro
- **Ratio** : toujours 16:9 (paysage) pour le site
- **Résolution** : générer en haute résolution puis exporter à ~1920x1080 ou 2560x1440
- **Compression** : exporter en PNG, puis optimiser avec `pngquant` ou `tinypng` pour le web (viser < 500KB par image)
- **Cohérence** : garder le même seed/style ref si possible (sur Midjourney : `--sref` avec une des images existantes)
- **Midjourney tip** : ajouter `--ar 16:9 --style raw --s 250` à la fin de chaque prompt
- **Flux tip** : utiliser le mode "ultra" avec guidance scale ~7.5
